## Review

Recommended A for scanning many dates with less repeated framing. B makes the existing strip useful as navigation and supports richer saved detail, but hides cross-day comparison. C compresses long history into weekly groups but adds a disclosure level. All rows are read-only; no-data duration is distinct from zero. The row chevron in A should point up while expanded. Exact iconography and touch sizes will use app components, not copied raster geometry. At narrow widths, keep dates unbroken and reflow details rather than shrink text. For non-timed activities, omit the entire Recorded time column if the displayed records have no measured time; show actual saved selections or session summaries where meaningful. Avoid presenting every activity as a timer history.
